## 🚀 Getting Started

### 1. **Clone the repository**

```sh
git clone https://github.com/Ripupz/stuggy_app.git
cd stuggy_app
```

### 2. **Install dependencies**

```sh
npm install
```

### 3. **Start the development server**

```sh
npm start
```
or
```sh
expo start
```

### 4. **Run on your device or emulator**

- Press `a` for Android emulator
- Press `i` for iOS simulator (Mac only)
- Scan the QR code with Expo Go app on your phone

---

## 📁 Project Structure

- `src/app/` — Main app pages (routes)
- `src/lib/utils/` — Shared utilities and components (e.g., `navbar.tsx`, `userCourses.tsx`)
- `assets/` — Images and fonts

---

## 🛠️ Main Features

- Pomodoro timer
- Forum discussion
- Score tracking and statistics
- Bottom navigation bar

---

## 📝 Notes

- Make sure you have [Node.js](https://nodejs.org/) and [Expo CLI](https://docs.expo.dev/get-started/installation/) installed.
- If you encounter dependency issues, try deleting `node_modules` and `package-lock.json`, then run `npm install` again.
